A responsive multi-section website built using **HTML5** and **Bootstrap 5**.

## Features

- Responsive Bootstrap Navbar
- Image Carousel with overlay
- About Us section
- Services section with cards
- Responsive Contact Form
- Responsive layout using Bootstrap grid
- Bootstrap buttons and components
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- Bootstrap 5.2.3
- Bootstrap JavaScript
- Unsplash Images

## Sections

- Navbar
- Home / Hero Carousel
- About Us
- Services
- Contact Us
- Footer
